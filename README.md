# Todo List App

## A full-stack CRUD application built with React, TypeScript, Express, and PostgreSQL.

## Features:

- View todos
- Create new todo
- Mark todo as completed
- Delete todo

## Frontend Technologies:
 React, Typescript, Axios, Vite

## Backend Technologies:
Express.js, Node.js, TypeScript, PostgreSQL


## Running the Project:
**Frontend/ Backend:**
- npm install 
- npm run dev
